# 🏗️ work-telegram-bot

> Telegram-бот для управления строительными проектами и задачами — прямо из мессенджера.

Бот позволяет прорабу или менеджеру вести стройку без таблиц и бумаги: создавать проекты,
ставить задачи исполнителям, контролировать сроки и бюджет, фиксировать выполнение фотографиями
и выгружать отчёты — всё в интерфейсе Telegram.

## ✨ Возможности

- 📋 **Проекты** — полный CRUD, прогресс в процентах, поиск, фильтрация и сортировка
- ✅ **Задачи** — назначение исполнителей, дедлайны, подсветка просроченных, фотофиксация работ
- 🧱 **Этапы и вехи** проекта
- 💰 **Бюджет** — план/факт по проекту
- 👷 **Мастера и исполнители** — справочник, редактирование ФИО
- 🔐 **Роли и контроль доступа (RBAC)**
- 🏠 **Карточка объекта и заказчика**
- 📦 **Реестр материалов** — заявки и поставка
- 🤝 **Приёмка работ**
- 📊 **Дашборд портфеля** проектов
- 🧾 **Журнал изменений (audit log)**
- 📁 **Экспорт отчёта** по проекту в CSV

## 🧩 Архитектура

Проект разбит на слои по принципам чистой архитектуры:

```
cmd/bot            точка входа: инициализация БД, бота и цикла обновлений
internal/
  ├── config       конфигурация (переменные окружения)
  ├── database     SQLite: схема и CRUD-операции
  ├── fsm          конечный автомат диалогов (пошаговый ввод данных)
  ├── handlers     обработчики команд, колбэков и отчётов
  ├── keyboards    инлайн- и reply-клавиатуры
  └── models       доменные модели
```

Диалоги с пользователем построены на **конечном автомате (FSM)** — это позволяет вести
пошаговый ввод (например, создание проекта) без потери состояния между сообщениями.

## 🛠️ Технологии

- **Go 1.25**
- [go-telegram-bot-api/v5](https://github.com/go-telegram-bot-api/telegram-bot-api) — клиент Telegram Bot API
- [modernc.org/sqlite](https://modernc.org/sqlite) — SQLite на чистом Go (без cgo)
- [godotenv](https://github.com/joho/godotenv) — загрузка переменных из `.env`

## 🚀 Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. В корне проекта создай файл `.env`:

   ```env
   TELEGRAM_TOKEN=123456:ABC-DEF...
   ```

3. Установи зависимости и запусти:

   ```bash
   go mod download
   go run ./cmd/bot
   ```

   База данных SQLite создаётся автоматически в каталоге `data/` при первом запуске.

## 🧪 Тесты

Проект покрыт unit-тестами (обработчики, доступ, отчёты, FSM и др.):

```bash
go test ./...
```

## 📂 Структура данных

Все локальные данные (`.env`, база `*.db`, каталог `data/`, собранные бинарники) исключены из
репозитория через `.gitignore` и не попадают в систему контроля версий.
